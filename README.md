# NexusKit

Ferramenta para o cliente do League of Legends.

## Download

Baixe o `NexusKit.exe` na página de [Releases](https://github.com/alefaria577/Nexuskit/releases/latest). Não precisa instalar nada, é só abrir o arquivo.

## Como usar

1. Abra o cliente do League of Legends.
2. Abra o `NexusKit.exe`.
3. Marque a opção **Auto accept**.

Pronto! Sempre que a partida for encontrada, a fila será aceita automaticamente.
